Features

Built for playing, not for modding

No mods, no game files

It only reads the screen, so it works where mods can't: cloud streaming like GeForce NOW, any store, any version.

A hotkey that always fires

A spare mouse button or any key, read straight from the input device, so it works under Wayland and while the game has focus.

On a second screen

The translation opens in a browser window you can keep anywhere, like the Steam Deck's built-in screen while you play on a monitor.

100+ languages

From Polish, Japanese and Hindi to Silesian, Kashubian and Latin.

Keeps the voice of the game

Names, tone and style stay intact, and languages with grammatical gender address your character correctly.

Free and private

Bring your own key; Gemini, OpenRouter and Mistral have free tiers. Only the dialogue window goes to the provider you pick. No accounts, no telemetry.

FAQ

Questions

Which games does it work with?

Any game that shows its dialogue as text on screen. You mark where the dialogue window is once, and can tell it the game's name for better translations.

Does it run on Windows or macOS?

Not yet. Releases are built for x86_64 Linux, which includes SteamOS on the Steam Deck.

Which AI provider should I pick?

Start with Gemini, the default: a key from Google AI Studio is free. If you hit its rate limits, see the other AI providers.
