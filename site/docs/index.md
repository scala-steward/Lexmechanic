Lexmechanic is a small daemon. Press its hotkey during a conversation in a game, and it takes a screenshot, crops it
to the dialogue window, has an AI model translate it, and shows the result on a local web page.

1. [Install]({% link docs/install.md %}) the prebuilt binary, or [build it from source]({% link docs/build-from-source.md %}).
2. Do the [first run]({% link docs/first-run.md %}): give it access to the hotkey and mark the dialogue window.
3. Get a key from one of the [AI providers]({% link docs/ai-providers.md %}) and enter it in the advanced settings.

Optional extras:

- A [desktop shortcut]({% link docs/desktop-shortcut.md %}) to start and stop it from the app menu.
- [Linux setup]({% link docs/linux-setup.md %}) for other desktops, a kiosk-style window, or a second screen.
